Wire

Send files straight from your device to theirs. Nothing is uploaded to a server — a small local relay just introduces the two of you, then gets out of the way.

This is the small local server's address, not where your files go — files travel directly between browsers. Run it with node server.js. If this page is loaded over https (e.g. GitHub Pages), the server address must start with wss:// (use a tunnel like ngrok) or your browser will block it.
